# Data Engineering Mindmap — v2 Roadmap

This roadmap outlines planned domain expansions and new concept nodes for **Version 2.0** of the Data Engineering Universe Mindmap.

---

## 🚀 Domain Expansions Planned for v2

### 1. AI & MLOps Engineering (New Primary Domain 11)
- **Feature Stores**: Feast, Tecton, Hopsworks, Databricks Feature Store [A]
- **Model Serving Infrastructure**: Triton Inference Server, TorchServe, vLLM, Seldon Core [X]
- **LLMOps & Vector Databases**: Pinecone, Qdrant, Milvus, Weaviate, Pgvector [A]
- **RAG Architecture**: LangChain, LlamaIndex, Chunking Strategies, Hybrid Search [A]
- **Model Monitoring & Drift**: Evidently AI, Arize AI, Fiddler [A]

### 2. Quantum Data Engineering & Advanced Distributed Compute (New Primary Domain 12)
- **Quantum Query Engines**: Qiskit, Cirq, Quantum Database Indexing [X]
- **GPU-Accelerated Compute**: RAPIDS cuDF, Spark-RAPIDS, Polars-GPU [A]
- **WebAssembly Engine Plugins**: Wasmtime in Redpanda/Envoy, Rust-Wasm Pipelines [X]
