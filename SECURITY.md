# Security Policy & Vulnerability Disclosure

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest (Production) | :white_check_mark: |

## Reporting a Vulnerability

We prioritize the security and confidentiality of our data systems and users. If you discover a vulnerability or potential security flaw, please report it promptly and responsibly:

- **Security Contact**: [santu.jammi@gmail.com](mailto:santu.jammi@gmail.com)
- **Security.txt**: `https://moderndataengineer.uk/.well-known/security.txt`

Please do **NOT** open public issues or pull requests for security vulnerabilities.

### Submission Guidelines

When reporting an issue, please include:
1. A clear description of the vulnerability, including affected endpoints, components, or parameters.
2. Step-by-step reproduction instructions or a minimal proof of concept (PoC).
3. The potential impact of the issue (e.g., privilege escalation, data exposure, XSS).

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours
- **Triage & Remediation Plan**: Within 7 business days
- **Coordinated Disclosure**: 90-day coordinated disclosure period before public reporting
