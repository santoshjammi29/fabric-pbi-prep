             .orderBy(F.col("txn_date").cast("timestamp").cast("long"))

    .withColumn("dense_rank", F.dense_rank().over(w_dept))

💡 RangeBetween vs RowsBetween: rangeBetween handles calendar days and gaps; rowsBetween operates strictly on physical row indices.

💾 Caching, Persistence Levels & Cleanup Memory Management 
from pyspark import StorageLevel

# Cache: MEMORY_AND_DISK_DESER (Default)
df_cached = df.cache()

# Persist with Serialized Kryo (Saves up to 3x RAM)
df_persisted = df.persist(StorageLevel.MEMORY_ONLY_SER)

# MANDATORY: Evict from RAM when actions complete!
df_cached.unpersist()
  • When to Cache: Cache ONLY when a DataFrame is reused across 2+ separate downstream actions.
  • Over-caching Antipattern: Starves Unified Execution Memory, forcing shuffle spills to disk!
🔁 Streaming foreachBatch Microbatch Processing Streaming Sink 
def process_micro_batch(micro_df, batch_id):
    # Cache microbatch if referenced in multiple merges
    micro_df.persist()
    
    # ACID Merge microbatch directly into Delta Silver
    (DeltaTable.forName(spark, "silver.txns").alias("t")
     .merge(micro_df.alias("s"), "t.id = s.id")
     .whenMatchedUpdateAll()
     .whenNotMatchedInsertAll()
     .execute())
    
    micro_df.unpersist()

query = (stream_df.writeStream
    .foreachBatch(process_micro_batch)
    .option("checkpointLocation", "/chk/silver")
    .start())
⚡ foreachBatch Superpower: Allows writing a streaming pipeline into non-streaming sinks, running multi-table merges, and executing deduplications per microbatch.
